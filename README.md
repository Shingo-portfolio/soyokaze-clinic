# 在宅医療クリニックのHPサイト

架空の医療法人「そよかぜ会(仮名)」のホームページを、HTML / CSS / JavaScript でコーディングした見本です（31ページ）。実在の法人・クリニック・人物とは関係ありません。

- 公開ページ: https://shingo-portfolio.github.io/soyokaze-clinic/
- ページ: `index.html`（トップ）, `page.html?p=…`（法人の紹介・診療の案内・関係者向け・採用・お知らせ・お問い合わせなど23ページ）, `clinic.html?id=…`（各クリニック7院）
- クリニック・院長・お知らせなどの中身は `data.js` と `pages.js` の表にまとめ、`script.js` が表から画面を組み立てます。クリニックを1院増やすときは表に1件足すだけです
- クリニック一覧では、診療エリアの地図の番号から各院のページへ移れます
- 相談フォームは、送ると同じページで「見本のため送信していません」の表示に切り替わります。入力した内容はどこにも送りません
- パソコンとスマホの幅に対応しています
- 写真の出典: `CREDITS.md`（Unsplash の無料写真と、AI で作った実在しない人物の写真）
